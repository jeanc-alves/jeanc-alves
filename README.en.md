### 👨‍💻 About Me

I am a **Full Stack Developer** with 5+ years of practical experience designing, building, and scaling modern web applications, high-throughput REST APIs, distributed microservices, and responsive user interfaces.

Currently at **Inovando Software**, I develop and evolve mission-critical enterprise ERP systems, participating in every stage of the software lifecycle: business requirements refinement, technical architecture, automated testing, code reviews, and production releases.

Beyond full-stack web development, I am deeply engaged in **AI Engineering applied to software workflows**, building and maintaining open-source **Local RAG** tools, vector semantic search pipelines, and **Model Context Protocol (MCP)** servers to integrate autonomous AI agents into modern development environments.

- 🔭 **Core Focus:** API Architecture, system integrations, complex business logic, and database query optimization.
- ⚡ **Performance-Driven:** Proven track record of slashing critical ERP processing bottlenecks from **50–90 seconds down to <15 seconds**.
- 🧠 **AI & Innovation:** Creator and maintainer of [`@inovan.do/obsidian-rag-tools`](https://github.com/inovando/obsidian-rag-tools), bridging local vector search, RAG, and MCP 2.0 servers.
- 🌱 **Continuous Learning:** Exploring AdonisJS v7, Clean Architecture, event-driven microservices, and multi-agent AI orchestration.

### 🚀 Key Results & Engineering Highlights

- ⚡ **ERP Performance Engineering:** In-depth profiling and refactoring of high-volume relational data operations. Optimized SQL queries, engineered strategic indices, decoupled synchronous flows with background queues, and optimized React/Next.js re-renders, reducing processing times from **50–90s down to <15s** (~80% throughput improvement).
- 🤖 **MCP Server & Local RAG (`obsidian-rag-tools`):** Designed and published an NPM package and MCP 2.0 server featuring local vector semantic search (ONNX embeddings via `@xenova/transformers`), hybrid search (RRF + BM25), and guideline/context management for AI coding assistants (Claude, Cursor, Antigravity, VS Code).
- 🛡️ **Resilient Legal Automation Microservice:** Built an asynchronous integration and data persistence pipeline using AdonisJS 5, TypeScript, Apache Kafka, Redis, and BullJS, featuring message queues, audit logs, and automated retry mechanics.
- 🔍 **Contract Calculation & Audit Engine:** Developed an iterative calculation tool to inspect complex service contracts, track execution iterations, uncover business rule ambiguities, and validate contract data transparently with stakeholders.
